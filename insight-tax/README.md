# Insight Tax landing page

Single-page site for Insight Tax. Static HTML, no build step. Open `index.html` or upload the `insight-tax/` folder to any static host.

## Files
- `index.html`: the full page (inline CSS and JS)
- `assets/logo.svg`, `assets/logo-light.svg`: logo for light and dark backgrounds
- `assets/favicon.svg`, `assets/apple-touch-icon.png`: browser and phone icons
- `assets/hero.svg`, `assets/expat.svg`: section illustrations
- `assets/og-image.png`: 1200x630 preview image for link sharing

## Fill in before going live (search the HTML for `OWNER:`)
1. ABN and Registered Tax Agent Number in the footer.
2. Testimonials: the three reviews are samples. Replace them with real client reviews (with permission) and delete the placeholder tags.
3. Pricing: add starting prices if desired, or keep the "Fixed fee" wording.
4. Team photos: replace the initials circles with headshots.
5. Quote form: it currently opens the visitor's email app addressed to info@insighttax.com.au. Connect a form service (Formspree, Netlify Forms, etc.) for direct submissions.
6. Credentials strip: confirm each claim (TPB registration, IPA membership, CA on staff) is current.

## Design notes
Structure and feel follow the Bright!Tax homepage pattern: navy and orange palette, deadline banner, quote-first hero, trust strip, services grid, how-it-works steps, pricing cards, reviews, team, FAQ and quote form. The Insight Tax name, logo, copy and illustrations are original, so the site reads as familiar without copying Bright!Tax branding.
